# Senses Frontend

Este directorio contiene el frontend de Senses.

## Aplicacion

El codigo fuente se encuentra en `frontend_project_centropsicologico_pisw2025-main/`.

```bash
cd frontend_project_centropsicologico_pisw2025-main
npm install
npm run dev
```

La aplicacion se inicia normalmente en `http://localhost:5173`.

## Configuracion de API

Cree un archivo `.env` dentro de `frontend_project_centropsicologico_pisw2025-main/` para usar una API local u otra instancia:

```env
VITE_API_URL=http://localhost:3000
```

Consulte `frontend_project_centropsicologico_pisw2025-main/README.md` para ver los comandos de compilacion y la estructura de la aplicacion.
